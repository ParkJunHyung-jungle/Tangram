# 주문 조각 PoC

Unity 6000.3.22f1 프로젝트다. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누르면 시작 화면이 표시된다. 현재 Windows 빌드는 `Build/w10-b4-tangram-deck-building.exe`다. 게임 진행은 저장되지 않는다.

- 손패 도형을 드래그해 도안 위에 놓는다. 클릭으로 선택한 뒤 격자를 클릭하는 방식도 사용할 수 있다. R 또는 우클릭으로 회전하고 Esc로 계속하기·타이틀·종료 메뉴를 연다.
- 도안 외곽선이나 오른쪽 도안 항목을 드래그해 3행 6열 격자 안에서 옮긴다. 도안이 겹치거나 격자 밖에 놓이는 이동은 허용하지 않는다. 새 도안을 놓을 공간이 없으면 다른 도안을 옮긴 뒤 오른쪽 항목을 격자로 끌어 놓는다.
- 배치한 턴과 무관하게 조각을 이동하거나 손패로 회수할 수 있다. 손패는 최대 7장이며, 이번 턴의 미시전 배치만 회수 시 배치 횟수를 돌려준다. 각 도안 오른쪽의 포기 버튼은 해당 도안만 비운다.
- 잔상 조각은 첫 시전 뒤 남고 다음 시전 뒤 버려진다. 회수·재배치로 시전 이력을 초기화할 수 없으며, 이미 시전한 배치 비용은 환불되지 않는다. 버림 더미로 보내거나 새 전투를 시작하면 잔상 이력을 초기화한다.
- 불씨와 방벽은 각각 정사각형 한 칸과 1/4 삼각형으로 완성한다. 두 추가 도안을 모두 얻은 뒤에는 보상으로 특수 카드 4종이 모두 표시된다.
- 기본 실행 크기는 1280×720이다. 다른 화면 비율에서도 내용 전체를 중앙에 맞춰 표시한다.
- 턴 종료 위의 예상 피해는 살아 있는 적의 다음 공격 합계에서 현재 방어를 뺀 값이다. 보상 화면에서는 특수 조각의 모양이나 새 도안의 형태를 확인할 수 있다.

2026-11-09의 이전 규칙 논리 시뮬레이션에서는 불씨 반복 전략이 30회 모두 패배했고, 직사각형을 방벽에 우선 사용하는 전략은 30회 중 18회 승리했다. 현재의 1.25칸 방벽에는 직사각형을 배치할 수 없고, 당시 실험은 실제 보상 후보 제한도 반영하지 않았다. 따라서 현재 규칙의 완주 가능성·재미·난이도 검증 결과로 사용할 수 없다.

이전 버전에서 Windows 빌드 생성과 프로세스 시작을 확인한 기록이 있다. 현재 수정본의 빌드·완주 검증 결과와는 구분한다.

## 2026-11-10 수정 및 검증

잔상 카드의 시전 이력과 배치 비용 확정 상태를 분리했다. 회수·재배치 후에도 잔상 이력이 유지되고, 시전한 배치 비용은 회수·도안 포기로 환불되지 않는다. 카드·적·도안·배치 목록은 읽기 전용으로 공개한다. 도안 표시 좌표는 논리 마스크에서 생성하며, 이전 두 제작판의 미사용 도안 교체 API는 제거했다.

화면 전체를 비율에 맞춰 중앙에 배치하고, 드래그 중 회전 미리 보기·직사각형 안내 고스트·도안 전체 획득 후 네 가지 보상 배치를 수정했다. UI 갱신·비활성화 시 진행 중 드래그를 취소하고, 드래그 중 반복 전역 검색을 제거했다. 추가 Inspector 연결은 없다.

- Unity의 기존 참조와 컴파일 옵션을 사용한 전체 게임 스크립트 컴파일 통과. `.meta` 누락 및 중복 GUID 없음.
- 열려 있던 Unity의 Untitled 장면에서 자동 생성되는 게임 UI로 Play Mode 진입과 종료를 확인했다. SampleScene을 직접 연 플레이 검증과는 구분한다.
- 새 게임과 첫 손패, 클릭 배치·기본 3회 배치 차감, 첫 배치 설명, 방벽 완성 후 수동 시전·방어 7 적용·안내 종료를 확인했다.
- 적 공격 4를 방어해 체력 50 유지, 다음 턴 방어 0·배치 3회·5장 드로우, 미완성 조각 유지, 이전 턴 조각 회수 후 배치 3회 유지를 확인했다. 종료 후 Unity Console의 로그·경고·오류는 모두 0개였다.
- 잔상 회수·재배치, 네 가지 보상, 드래그 중 회전·Esc 취소, 1024×768 화면, 6전투 완주는 실제 조작 검증이 남아 있다. PRD 14절의 해당 수용 기준으로 확인한다.
- Unity Editor의 Windows Intel 64-bit 빌드가 49초 만에 성공했다. 실행 파일은 `Build/w10-b4-tangram-deck-building.exe`이며, Unity 서비스 없이 빌드했다. 컴퓨터 사용 도구가 해당 앱의 사용 미승인으로 실행 요청을 거부해 빌드 실행·직접 조작은 확인하지 못했다.
- Unity 가져오기·빌드 중 `ProjectSettings/GraphicsSettings.asset`, `ProjectSettings/ShaderGraphSettings.asset`, `Assets/Settings/PC_RPAsset.asset`, `Assets/Settings/UniversalRenderPipelineGlobalSettings.asset`의 저장 시각이 갱신됐다. 원본 대비 내용 차이는 미확인이며 기존 변경 보존을 위해 임의로 되돌리지 않았다. 빌드에서 임시 생성한 PerformanceTestRun 자산은 빌드 종료 후 자동 제거됐다.

남은 수동 확인은 SampleScene을 열고 Play → 잔상 보상 획득 → 첫 시전 후 같은 턴 회수·재배치·다음 시전으로 진행한다. 시전 직후 회수·포기에서는 배치 횟수가 늘지 않고, 다시 배치한 잔상은 다음 시전 후 버려져야 한다. 두 도안을 모두 획득한 다음 보상에는 특수 카드 네 종류가 모두 보여야 한다. Game 뷰를 1024×768로 바꿔 오른쪽 버튼이 보이는지 확인하고, 드래그 중 포인터를 멈춘 채 R·우클릭으로 미리 보기 갱신, Esc 후 계속하기에서 잔여 드롭이 없는지 확인한다.

빌드 실행 검증은 `Build/w10-b4-tangram-deck-building.exe`를 열고 시작 → 조각 배치 → 시전 → 턴 종료를 확인한 뒤 보상 선택을 포함해 6전투를 완주한다.
