# 주문 조각 PoC

Unity 6000.3.22f1 프로젝트다. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누르면 시작 화면이 표시된다. Windows 빌드는 `Build/SpellFragments.exe`에 생성할 수 있다. 게임 진행은 저장되지 않는다.

- 손패 도형을 드래그해 도안 위에 놓는다. 클릭으로 선택한 뒤 격자를 클릭하는 방식도 사용할 수 있다. R 또는 우클릭으로 회전하고 Esc로 선택을 해제한다.
- 도안 외곽선이나 오른쪽 도안 항목을 드래그해 3행 6열 격자 안에서 옮긴다. 도안이 겹치거나 격자 밖에 놓이는 이동은 허용하지 않는다. 새 도안을 놓을 공간이 없으면 다른 도안을 옮긴 뒤 오른쪽 항목을 격자로 끌어 놓는다.
- 이번 턴의 조각은 클릭한 뒤 이동하거나 회수할 수 있다. 이전 턴 조각은 어둡게 표시되며 잠긴다. 각 도안 오른쪽의 포기 버튼은 해당 도안만 비운다.
- 턴 종료 위의 예상 피해는 살아 있는 적의 다음 공격 합계에서 현재 방어를 뺀 값이다. 보상 화면에서는 특수 조각의 모양이나 새 도안의 형태를 확인할 수 있다.

2026-11-09 논리 시뮬레이션에서는 불씨 반복만 사용한 30회가 모두 패배했고, 직사각형을 방벽에 우선 사용하는 단순 전략은 30회 중 18회 승리했다. 이 실험은 특수 보상 종류를 임의로 선택할 수 있어 실제 보상 후보 제한을 반영하지 않았다. 플레이어의 재미나 난이도 검증으로 볼 수 없으며 초기 PRD 수치는 변경하지 않았다.

Windows 빌드 생성과 프로세스 시작을 확인했다. 빌드에서 직접 조작해 6전투를 완주하는 검증은 아직 하지 않았다.
